# Versioning

The SDK uses semantic versioning:

```text
MAJOR.MINOR.PATCH
```

## Rules

- Increment `MAJOR` when compatibility is broken.
- Increment `MINOR` when public API features are added without breaking compatibility.
- Increment `PATCH` for fixes that keep the public API stable.

## Git tags

Each published SDK release should have a Git tag:

```text
v0.1.0
```

The tag identifies the exact headers, documentation and libraries delivered to the user.
